# Degla website

Unzip this package. Upload the contents of this folder to your GitHub repository, keeping index.html at the repository root and preserving the assets, dock, and swarm folders. Do not upload the ZIP or the large standalone preview HTML.

This is a static website; no build step is required. Includes the supplied logo, revised dock and VTOL, and latest specifications.

To preview locally: run `python3 -m http.server 8000` in this folder, then open http://localhost:8000.

The pilot request form opens the visitor’s email application; it does not automatically send email.
